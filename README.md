# handwriting-to-text-converter
An OCR application to convert handwritten notes to digital text using Python, OpenCV, and Streamlit.
## Features
* **Image Preprocessing:** Uses OpenCV to enhance image quality (grayscale, thresholding) for better accuracy.
* **OCR Integration:** Utilizes [Tesseract/EasyOCR] to extract text from images.
* **Interactive UI:** Built with Streamlit for a seamless user experience.

## Tech Stack
* Python
* OpenCV
* Streamlit
* [Tesseract/EasyOCR]

## How to Run
1. Clone the repo: `git clone https://github.com/kartikkumara380-a11y/handwriting-to-text-converter.git
cd handwriting-to-text-converter`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py`
